📚 What's Happening?

  • Producer: Generates 10 random numbers/second → Redis list (fast writes)
  • Redis Queue: Buffers events in memory (handles bursts)
  • Consumer: Background task processes batches every 5 seconds → Postgres
  • Result: Decoupled system — Redis absorbs spikes, Postgres gets stable batches
